# 小和的奇妙数学之旅 — 可交互 Demo

这是一个用你上传的漫画页面做的最小可运行原型，用来验证"翻页阅读 + 点击展开知识讲解"这种交互形式的感觉。

## 怎么在本地跑起来

**方法一：直接双击打开（最简单，适合先看效果）**

直接双击 `index.html`，用浏览器打开即可。翻页、点星星看知识卡这些交互都能正常用。

局限：这种方式下 Service Worker（离线缓存）和"添加到主屏幕"这两个 PWA 特性不会生效，因为浏览器要求通过 `http(s)://` 而不是 `file://` 访问才能用这些能力。

**方法二：本地起一个小型服务器（体验完整 PWA 效果，包括"安装到主屏幕"）**

如果电脑装了 Python（大多数 Mac/Linux 自带）：

```bash
cd 这个文件夹的路径
python3 -m http.server 8080
```

然后在电脑浏览器打开 `http://localhost:8080`，或者让手机和电脑连同一个 WiFi，在手机浏览器里打开 `http://你电脑的局域网IP:8080`（比如 `http://192.168.1.5:8080`），就可以体验"添加到主屏幕"了：

- **iPhone（Safari）**：打开网页 → 点击分享按钮 → "添加到主屏幕"
- **安卓（Chrome）**：打开网页 → 右上角菜单 → "添加到主屏幕" / 会自动弹出安装提示

## 目录结构

```
index.html      主程序（翻页 + 知识卡逻辑全在这一个文件里）
manifest.json   PWA 配置（图标、名称、启动方式）
sw.js           离线缓存脚本
images/         8 页漫画图（从你的 PDF 里提取的）
icons/          App 图标（用封面裁剪生成的，只是占位，正式做的时候可以换）
```

## 这个 demo 演示了什么

- 左右滑动或点击箭头翻页，模拟真实翻漫画的手感
- 第 6、7 页上放了示例的 ⭐ 知识点热区，点击后从底部弹出"知识卡"：
  - **石子记数法**：一个可以真的点击"羊出门/羊回家"来体验"一一对应"思想的小组件
  - **进位加法 / 退位减法**：点"下一步"逐步演示竖式计算过程，而不是一次性甩一段文字
- 其余页面（1-5）目前没有知识点热区，只是能翻页看漫画——这几页可以按同样的模式后续再加

## 如果你要接着做下去

1. 先确定每一页/每一格要挂哪些知识点、配什么样的讲解或小互动（文字？图示？可操作小游戏？）
2. 把这些内容整理成类似 `CARDS` 这样的数据结构（在 `index.html` 里能看到现在的写法），方便以后维护
3. 图片建议做压缩/裁切优化（现在是从 PDF 直接导出的整页图，体积偏大），正式版可以按每一格单独切图，方便未来做"点击某一格放大"之类的效果
4. 正式发布时记得看看这几个：网址如果要给中国大陆用户访问，参考我们之前聊的国内托管方案；图标现在只是临时用封面裁的，正式版建议单独设计一个方形图标
